# Art Academy TLC

A complete 36-week high-school Visual Arts 1 course designed for independent homeschool use.

## What is included
- 36 weekly studio lessons
- Featured artist + “why this artist matters” context every week
- Technique mini-lectures
- Clear studio steps and finish checklists
- Quarter structure and grading
- Local progress tracking in the browser
- Portfolio milestones
- Responsive design for laptop, tablet, and phone

## Publish with GitHub Pages
1. Upload `index.html`, `styles.css`, `app.js`, and `.nojekyll` to the root of the `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save. GitHub will show the public site URL after deployment.

No build tools are required.

## Editing the curriculum
All course content is stored near the top of `app.js` in the `WEEKS` data array. Each week contains:
- title
- featured artist
- artist background
- artwork example
- mini lecture
- assignment
- studio steps
- checklist
- time
- materials

The original course sequence was expanded from the uploaded 9th Grade Visual Arts 1 homeschool syllabus.
